Bitesized Blackjack

A simple web-app for playing Blackjack

Bitesized Blackjack became a personal project after I was assigned to design the user interface for a blackjack game as part of an interview process. At first I was only supposed to create the UI and code a single page in simple HTML and CSS, there did not need to be any functionality. However, after spending so much time with the design I wanted to see the project come to life so I continued on to create a simple web-app that can be played on-line or installed to your phone to play a quick game on the go.
